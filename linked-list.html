Linked Lists — Master These Templates

Do not merely memorize the code. Understand what each pointer means. Most linked-list bugs come from losing the next node before changing a pointer.

Node Syntax

struct Node {
    int data;
    Node* next;
    Node(int x){ data=x; next=NULL; }
};
class Node {
    int data;
    Node next;
    Node(int x){ data=x; next=null; }
}

Traversal

Node* temp=head;
while(temp!=NULL){
    cout << temp->data << " ";
    temp=temp->next;
}

The Java idea is identical: Node temp=head; while(temp!=null){...; temp=temp.next;}

Reverse — MEMORIZE THE FOUR MOVES

save next → reverse pointer → move prev → move curr
Node* prev=NULL;
Node* curr=head;
while(curr!=NULL){
    Node* next=curr->next;
    curr->next=prev;
    prev=curr;
    curr=next;
}
head=prev;

Time O(n), extra space O(1).

Middle — Slow + Fast

Node* slow=head;
Node* fast=head;
while(fast!=NULL && fast->next!=NULL){
    slow=slow->next;
    fast=fast->next->next;
}
// slow is at the middle (exact convention depends on even length)

Cycle — Floyd’s Algorithm

bool hasCycle(Node* head){
    Node* slow=head;
    Node* fast=head;
    while(fast!=NULL && fast->next!=NULL){
        slow=slow->next;
        fast=fast->next->next;
        if(slow==fast) return true;
    }
    return false;
}

Why? Fast gains one node per iteration on slow inside a cycle, so they eventually meet.

Kth Node From End

Node* slow=head;
Node* fast=head;
for(int i=0;i<k;i++) fast=fast->next;
while(fast!=NULL){
    slow=slow->next;
    fast=fast->next;
}
return slow;

Keep a gap of k nodes. When fast reaches the end, slow is k positions from the end.

Rotation — The Mental Trick

For a right rotation, find length, connect tail to head to form a circle, then break the circle at the new tail. The important insight is:

rotation = make circular + break at the correct point

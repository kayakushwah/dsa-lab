# JTG OA Lab 🧠

An interactive, gamified DSA study site for the JTG online assessment.
Covers DSA core, patterns, linked lists, trees/BST, output traps, and quick revision.

Built with HTML/CSS/JS and hosted through Streamlit.

## Run locally
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Features
- XP, levels and daily streaks, with progress saved in the browser
- Step-by-step visualizers for two pointers, linked list reversal and tree traversals
- Quizzes, a pattern detective game, a predict-the-output arena and flashcards
- Mobile-friendly layout

Code Given → Predict the Output

Do not guess. Track state line-by-line. These traps are small enough to memorize and powerful enough to save marks.

1. ++x vs x++

Post-increment

int x=5;
int y=x++;
// y=5, x=6

Use first, then change.

Pre-increment

int x=5;
int y=++x;
// x=6, y=6

Change first, then use.

2. Pointers

int x=10;
int *p=&x;
*p=50;
cout << x; // 50

p stores an address; *p accesses the value at that address.

3. Pointer-to-pointer

int x=10;
int *p=&x;
int **q=&p;

Relationship: q → p → x. Therefore x, *p and **q all evaluate to 10.

4. Array Pointer Equivalence

int a[]={10,20,30};
cout << *(a+1); // 20
cout << 1[a];   // 20

Because a[i] is equivalent to *(a+i) in C/C++.

5. Recursion Output

Print before recursion

void f(int n){
    if(n==0) return;
    cout<<n<<" ";
    f(n-1);
}

f(3) → 3 2 1

Print after recursion

void f(int n){
    if(n==0) return;
    f(n-1);
    cout<<n<<" ";
}

f(3) → 1 2 3

If there is printing both before and after the recursive call, write the descent and then the unwind. Example: 3 2 1 1 2 3.

6. static local variable

void f(){
    static int x=0;
    x++;
    cout<<x<<" ";
}
f(); f(); f();

Output: 1 2 3. A static local retains its value between calls.

7. break vs continue

for(int i=1;i<=5;i++){
    if(i==3) continue;
    cout<<i<<" ";
}

1 2 4 5

for(int i=1;i<=5;i++){
    if(i==3) break;
    cout<<i<<" ";
}

1 2

8. sizeof vs strlen

char a[]="hello";
cout<<strlen(a); // 5
cout<<sizeof(a); // 6

The array includes the terminating \0.

9. Java == vs equals()

String a=new String("hello");
String b=new String("hello");
System.out.println(a==b);
System.out.println(a.equals(b));

Output: false true. For objects, == checks reference identity; equals() can check content when implemented accordingly.

10. Java String immutability

String s="hello";
s.concat(" world");
System.out.println(s);

Output: hello. The concatenation returns a new String; it does not mutate the original.

11. C++ virtual dispatch

class A{
public:
    virtual void show(){cout<<"A";}
};
class B: public A{
public:
    void show(){cout<<"B";}
};
A* p=new B();
p->show();

Output: B. With a virtual function, the overridden function is selected dynamically through the base pointer.

12. Constructor order

In inheritance, the parent/base constructor runs before the child/derived constructor. Destruction is generally in reverse order.

13. Integer division

cout<<5/2;

2

cout<<5.0/2;

2.5

14. Switch fall-through

int x=2;
switch(x){
case 1: cout<<"A";
case 2: cout<<"B";
case 3: cout<<"C";
}

Output: BC. Without break, execution continues into later cases.

15. Bitwise mini-tricks

x ^ x = 0, x ^ 0 = x.

That is why XOR can find a unique element when every other element occurs twice.

2 ^ 3 ^ 2  // 3

Tree Traversal Without Panic

The fastest way to become comfortable with trees is to understand one recursive skeleton and move the “process node” line.

Tree Node

struct Node{
    int data;
    Node* left;
    Node* right;
};

Java: class Node { int data; Node left,right; }

The Three Traversals

NameOrderMemory trick
PreorderROOT → LEFT → RIGHTRoot comes PRE
InorderLEFT → ROOT → RIGHTRoot is IN the middle
PostorderLEFT → RIGHT → ROOTRoot comes POST/last

For:

        1
       / \
      2   3
     / \
    4   5

Preorder = 1 2 4 5 3
Inorder = 4 2 5 1 3
Postorder = 4 5 2 3 1

One Recursive Skeleton

void dfs(Node* root){
    if(root==NULL) return;

    // process root

    dfs(root->left);
    dfs(root->right);
}

Move processing:

  • before both calls → preorder
  • between calls → inorder
  • after both calls → postorder

Height

int height(Node* root){
    if(root==NULL) return 0;
    return 1 + max(height(root->left), height(root->right));
}

This definition counts nodes. Some problems define height in edges, so always inspect the convention.

Count + Sum

Count

int count(Node* root){
    if(root==NULL) return 0;
    return 1 + count(root->left) + count(root->right);
}

Sum

int sum(Node* root){
    if(root==NULL) return 0;
    return root->data + sum(root->left) + sum(root->right);
}

BST

Binary Search Tree rule:

left subtree values < root < right subtree values

Therefore inorder traversal of a valid BST produces values in sorted order.

bool search(Node* root,int x){
    if(root==NULL) return false;
    if(root->data==x) return true;
    if(x<root->data) return search(root->left,x);
    return search(root->right,x);
}

Balanced BST search ≈ O(log n); a skewed BST can degrade to O(n).

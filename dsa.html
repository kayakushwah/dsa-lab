Data Structures & Algorithms

The goal is not to memorize 100 algorithms. The goal is to recognize the structure of a problem and choose the data structure or pattern that reduces the work.

1. Big-O

Big-O describes how work grows as input n grows.

ComplexityMeaningTypical example
O(1)constantarray index access
O(log n)halving the search spacebinary search
O(n)one passlinear search
O(n log n)divide + linear combinemerge sort
O(n²)all pairs / nested n loopsnaive pair checking
O(2ⁿ)exponentialnaive subset recursion
OA trick: for(i=1;i<n;i*=2) is O(log n), not O(n). A loop of exactly 100 iterations inside an n-loop is still O(n).

2. Arrays

Access

int a[] = {10,20,30,40};
cout << a[2]; // 30

Index access is O(1).

Traversal

for(int i=0;i<n;i++)
    cout << a[i] << " ";

Traversal is O(n).

3. Two Pointers

Use this heavily when an array is sorted and the question asks about a pair or a target sum.

int l=0, r=n-1;
while(l<r){
    int sum=a[l]+a[r];
    if(sum==target) return true;
    if(sum<target) l++;
    else r--;
}
return false;

Recognition: sorted + pair + target → two pointers. O(n).

4. Sliding Window

For a fixed-size contiguous block, don't recompute the entire sum.

int sum=0;
for(int i=0;i<k;i++) sum+=a[i];
int ans=sum;
for(int i=k;i<n;i++){
    sum += a[i];
    sum -= a[i-k];
    ans=max(ans,sum);
}

Recognition: consecutive/contiguous + fixed k → sliding window.

5. Hashing

C++ frequency

unordered_map<int,int> freq;
for(int x:a) freq[x]++;

Java frequency

HashMap<Integer,Integer> freq = new HashMap<>();
for(int x:a)
    freq.put(x,freq.getOrDefault(x,0)+1);
Recognition: frequency, duplicate, “seen before”, pair sum in an unsorted array → hash map/set.

6. Prefix Sum

For repeated range-sum queries, build prefix sums once.

prefix[i] = prefix[i-1] + a[i]

For l > 0:

sum(l,r) = prefix[r] - prefix[l-1]

For l = 0, answer is prefix[r].

7. Binary Search

Use it when the search space is sorted or has a monotonic yes/no property.

int l=0,r=n-1;
while(l<=r){
    int mid=l+(r-l)/2;
    if(a[mid]==target) return mid;
    if(a[mid]<target) l=mid+1;
    else r=mid-1;
}
return -1;
Why l+(r-l)/2? It avoids overflow that can occur with (l+r)/2.

8. Recursion

Every recursive solution needs a base case and progress toward it.

int fact(int n){
    if(n==0) return 1;
    return n*fact(n-1);
}

For output questions, write the call stack. If printing happens before recursion, you see the descent; if after recursion, you see the unwind.

9. Stack + Queue

Stack = LIFO

Plates. Last in, first out.

stack<int> st;
st.push(10);
st.push(20);
st.top(); // 20
st.pop();

Brackets and next-greater problems often scream “stack”.

Queue = FIFO

Ticket line. First in, first out.

queue<int> q;
q.push(10);
q.push(20);
q.front(); // 10
q.pop();

Level-order tree traversal uses a queue.

11. Graph Basics

Graph = vertices + edges. For an undirected adjacency list:

vector<vector<int>> g(n);
g[u].push_back(v);
g[v].push_back(u);

DFS uses recursion/stack. BFS uses a queue. Traversing an adjacency list is typically O(V+E).
